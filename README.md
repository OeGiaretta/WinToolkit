# WinToolkit

![WinToolkit Logo](assets/logo.png)

WinToolkit is a collection of Windows command-line utilities designed to simplify daily system administration tasks.  
It gathers multiple .bat scripts in one place, offering quick access to tools for networking, diagnostics, automation, system cleanup, and more.

---

## 🚀 Features
- Network utilities (IP lookup, ping tools, DNS checks)
- System maintenance and cleanup
- Administrative shortcuts and automation scripts
- Text parsing and log utilities
- Simple, fast, and portable — no installation required

---

## 📁 Project Structure
```

/WinToolkit
├── tools/

```

---

## 🛠 Requirements
- Windows 10+
- Command Prompt (cmd.exe)
- Administrator permissions for some tools

---

## ▶️ How to Use
1. Clone the repository:
    ```sh
   git clone https://github.com/your-user/WinToolkit
    ```

2. Run the main script:

   ```sh
   WinToolkit.bat
   ```
